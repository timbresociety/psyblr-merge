# PR07 — Merge + Tier Progression

## Implemented scope

Added the Battle Camp merge vertical slice from F through C. Camp drag and touch selection both submit merge intent when a same-definition, same-tier occupied target is selected. The target instance survives in its existing cell, the source is removed, and protected Illuminati targets remain protected.

`@psyblr/contracts` now contains merge request/result/runtime contracts. The tutorial `MergeGateway` is a serialized local authority adapter with cached same-action results and participant reservations, so concurrent requests cannot both consume a pair. The Zustand store only applies authoritative results once and removes/remaps stale campaign placements and selected IDs.

Tier math is centralized in `@psyblr/game-rules`: F→SSS, canonical multipliers, deterministic HP/ATK/DEF rounding, next-tier deltas, max-tier detection, and form bands. Campaign snapshot construction and existing tier-visible summon UI use resolved instance tiers.

The merge tutorial now permits camp selection, completes the chain with `MERGE_COMPLETED { toTier: 'C' }`, and restores either merge step in Base with Spawn closed. Checkpoints are schema v4 and retain merge action IDs; v1–v3 migrate without dropping existing state.

The Base has matching-target glow, accessible invalid/pending feedback, restrained tier scale/pedestal treatment, and a short result-driven merge pulse. A world-visible progression panel shows the tier ladder, discovered/silhouette form bands, and exact HP/ATK/DEF delta while making clear that utility stats do not scale.
