# PR04 — Tutorial engine + Campaign onboarding

## Scope implemented

- Added `@psyblr/tutorial-core`, a pure interpreter over versioned tutorial definitions.
- Replaced the Campaign tutorial with granular open/select/identity/stats/skills/place/synergy/full-team/battle/manual/auto/complete steps.
- Added typed campaign interaction payloads, controller-level tutorial pause/resume, local checkpoint persistence, coach marks, and formation synergy UI.
- Applied Origin and Combat Function mechanics while building the immutable campaign combat snapshot.

## Architecture and boundaries

- `packages/tutorial-core` has no browser, React, Zustand, or PlayCanvas dependency. It resolves current steps, allowed actions, flat event payload matches, and deterministic transitions.
- `apps/web/src/tutorial/controller.ts` adapts interaction events, persists checkpoints, records first-summon/ready-actor context, and controls only the web combat interval. Combat core remains pure and unaware of tutorial state.
- `TutorialOverlay` owns DOM target measurement, focus styling, non-placement masks, compact coach copy, and explicit Continue events. `FormationSynergyPanel` is data-driven React UI.

## Campaign steps and event vocabulary

`campaign_open_inventory`, `campaign_select_summon`, `campaign_identity`, `campaign_stats`, `campaign_skills`, `campaign_place_first`, `campaign_synergy_intro`, `campaign_add_five`, `campaign_start`, `campaign_wait_skill`, `campaign_manual_skill`, `campaign_autocast`, `campaign_complete`, then `base_intro`.

The normalized event vocabulary is `INVENTORY_OPENED`, `SUMMON_SELECTED`, `SUMMON_DRAG_STARTED`, `SUMMON_PLACED`, `TEAM_SIZE_6`, `STATS_VIEWED`, `SKILLS_VIEWED`, `BATTLE_STARTED`, `FIRST_SKILL_READY`, `SKILL_1_CAST_MANUAL`, `AUTO_CAST_ENABLED`, `BATTLE_ENDED`, and `TUTORIAL_CONTINUE`. Battle end carries `victory`, `defeat`, or `draw`.

## Persistence and battle strategy

The versioned local checkpoint stores current/completed step IDs, tutorial context, starter inventory, battlefield placements, and a replayable battle checkpoint (immutable snapshot, seed, tick, accepted command log, Auto Cast and pause state). Invalid JSON/version data falls back safely to a fresh flow. Setup restores synchronously from `localStorage`; active battles reconstruct by replaying accepted commands to the saved simulation tick. Battle pause is controller-only, processes an accepted manual command with one deterministic tick, and resumes only after Auto Cast.

## Synergies

Threshold content now retains display copy plus typed effects. Rules resolve the highest satisfied threshold per Origin/Function and apply only to Summons carrying that trait. Rebel and Disruptor HP percentages add before rounding; Ascendant changes APS; Striker changes basic raw damage; Mastermind changes numeric Skill 1 magnitude; Controller changes applied status duration.
