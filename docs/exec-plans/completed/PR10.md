# PR10 — Opponent Camp + Steal

Added a read-only opponent Camp mode that reuses the Base world, protected Illuminati treatment, exposed target feedback, DOM accessibility fallback, and explicit STEAL SUMMON confirmation. Local tutorial authority creates a deterministic Raid Warden Camp with a guaranteed exposed target.

Added serializable opponent-camp/steal contracts and the production-shaped `claim-raid-steal` Edge Function plus transactional SQL RPC. The RPC locks the Raid and target, verifies win/ownership/exposure/capacity, transfers ownership and placement, records the steal, consumes the claim, and returns an idempotent action result.
