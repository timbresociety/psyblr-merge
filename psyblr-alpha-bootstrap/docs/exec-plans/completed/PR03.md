# PR03 — Deterministic campaign combat

## Scope implemented

- Added a deterministic six-summon-versus-six-creep campaign battle.
- Added manual Skill 1 casting, Auto Cast, battle result UI, and stable campaign interaction events.
- Added the three static creep archetypes and six data-driven starter Skill 1 mechanics.

## Architecture decisions

- `@psyblr/combat-core` is a pure TypeScript fixed-step simulator. The web battle session only builds an immutable snapshot, queues commands, advances the simulator, and presents its output.
- The simulation uses a 100 ms tick and integer positions (1,000 simulation units per board cell). PlayCanvas receives emitted simulation state; it does not determine combat outcomes.
- Damage is `max(1, round(raw * 100 / (100 + defense)))`; vulnerability increases raw damage before defense. Shield absorbs the resulting damage before HP.
- Battles time out at 45 seconds (450 ticks). Remaining HP plus shield determines the winner; equal totals draw.
- Skill mechanics are content-driven through a small vocabulary: `line_damage`, `aoe_slow`, `dash_aoe`, `taunt_shield`, `mark_vulnerability`, and `stun`.

## Content and tuning

- Brute: 620 HP, 48 ATK, 45 DEF, 0.75 APS, 1.1 range, 3.0 move speed.
- Scout: 420 HP, 36 ATK, 24 DEF, 1.1 APS, 1.0 range, 4.8 move speed.
- Shooter: 380 HP, 42 ATK, 20 DEF, 0.85 APS, 3.5 range, 3.2 move speed.
- Enemy formation has stable IDs and cells: Brutes `(2,1)/(5,1)`, Scouts `(1,2)/(6,2)`, Shooters `(3,0)/(4,0)`.

## Tests and verification

Ran from `psyblr-alpha-bootstrap/`:

- `npm run validate:content`
- `npm run typecheck`
- `npm run test`
- `npm run build`
- `npm run test:e2e`
- Focused desktop Playwright combat flow: `npx playwright test tests/e2e/shell.spec.ts --project=desktop-chromium --grep 'campaign combat' --reporter=line`

The deterministic unit suite verifies byte-equivalent replay, movement before range attacks, defense/death/end rules, command readiness/cooldown behavior, statuses, taunt targeting, and timeout resolution. The browser flow deploys all six, starts combat, manually casts a ready skill, enables Auto Cast, and reaches VICTORY.

## Known limitations

- Presentation uses lightweight primitives and simulation-state updates at the 100 ms combat tick; there are no final particle assets or per-frame interpolation adapters yet.
- Creep combat has no active skills by design.
